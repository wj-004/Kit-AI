Cómo explorar las tareas

Este árbol permite consultar los estados del plan y seguir qué tareas necesitan a otras. Cada tarjeta es una tarea; cada flecha va de un requisito a su dependiente. Una tarea puede tener varios requisitos.

  1. Buscá por ID o título. Combiná estados, módulo y alcance. Los números de cada estado corresponden al plan completo; el contador de resultados refleja los filtros.
  2. Seleccioná una tarea en la lista o el árbol para ver requisitos, dependientes, implementación, aceptación y evidencia. Los enlaces del detalle permiten saltar a tareas de otros filtros: se restablecen para mostrarlas.
  3. Usá Ver cadena completa para aislar sus requisitos y dependientes transitivos. Salir de la cadena vuelve a los filtros anteriores.
  4. El árbol abre a escala legible. Arrastrá el fondo para moverlo, desplazá con las flechas del teclado y acercá con los botones +/−. Ajustar encuadra todas las tareas filtradas. También podés usar la rueda del mouse o dos dedos para desplazar y Ctrl/⌘ + rueda para zoom.
  5. En móvil, usá la lista y desplazá la página hasta el detalle. Tab y Enter permiten recorrer las tareas; Escape cierra esta ayuda o el detalle.

Si un filtro oculta un requisito, el pie del gráfico informa cuántas conexiones quedan fuera. El detalle conserva la lista completa y el texto literal de las dependencias, junto a los demás campos de la tarea. El estado BLOQUEADO procede del plan; no se deduce automáticamente del color de los requisitos.

Los estados usan estos colores en tarjetas, lista, requisitos, dependientes y leyenda: pendiente gris, en curso azul, parcial ámbar, hecho verde, bloqueado rojo y fuera del alcance violeta. Las flechas toman el color del destino; seleccionar una cadena conserva esos colores.

El tema sigue la preferencia del sistema hasta que uses Tema oscuro; la elección se conserva para esta dirección del navegador, si permite almacenamiento local.

Si la evidencia de una tarea incluye imágenes, el detalle las muestra de a una en Evidencia visual; usá ‹ y › para recorrerlas y hacé clic en la imagen para ampliarla. Ampliada, también podés recorrerlas con las flechas del teclado.

Para abrir este árbol con actualización automática, ejecutá desde el proyecto:

python3 -B ver-plan.py

El navegador se abre con un puerto disponible. Al guardar cambios válidos en el plan, el árbol se actualiza conservando búsqueda, filtros, selección y zoom. Si el plan tiene errores, se conserva la última versión válida y se muestra el motivo.

Ctrl+C detiene el servicio. Para abrir una copia sin servidor, usá python3 -B ver-plan.py --static; la copia informa que no tiene sincronización.

Desde el detalle podés Editar tarea, Dar instrucción a Codex, Copiar contexto y Abrir Codex. Alcance autorizado corresponde al campo Capa del esquema: Solicitado es un pedido confirmado, Propuesto espera autorización y Excluido quedó fuera por una decisión explícita. No describe las capas de arquitectura. Descripción y alcance corresponde a Alcance; el resto de campos conserva el esquema del plan. ID, estado y dependencias son de consulta. Usá Volver al formulario desde una propuesta para seguir editándola, o Volver al detalle y Cerrar para regresar al árbol. Los borradores duran mientras la página siga abierta; cerrar el diálogo no los guarda. Una revisión nueva del plan no sobrescribe el borrador; ante un conflicto copiá la propuesta y recargá para revisarla sobre la versión vigente.

Para habilitar guardados, usá python3 -B ver-plan.py --allow-edit en una rama Git distinta de main/master. Elegí Validar y revisar cambios, revisá el diff y marcá la autorización antes de Guardar cambio autorizado. Cambiar un campo exige otra revisión. El servidor valida el plan completo y rechaza revisiones desactualizadas; guarda únicamente la tarea seleccionada. Revisá después git diff y prepará una Pull Request hacia main para aceptar el cambio.

El prompt contiene la tarea completa, prerrequisitos, dependientes, criterios, referencias e instrucción adicional. Copiar prompt usa el portapapeles; si no está disponible, selecciona el texto para copiarlo manualmente. Abrir Codex abre un chat local en la carpeta del proyecto y prepara el prompt del nodo seleccionado en el campo de mensaje; revisalo y envialo desde la app. Requiere Codex instalado y asociado al protocolo; el navegador puede pedir abrir la app. Si no se abre, copiá el prompt y pegalo en Codex. En otro equipo, regenerá el visor desde la ubicación local del proyecto. Los campos del plan se tratan como datos; el visor no ejecuta sus instrucciones.
